# Welcome to MDView

Read Markdown from Files, follow changes, and listen with installed system voices.

> [!TIP]
> Use the outline button to jump between sections. The More menu has Find, reading width, and Read Aloud.

## A quick checklist

The first checkmark asks before saving. Each tick then saves to this file; Undo is available above the document.

- [ ] Read this document
- [ ] Try a checkmark, then Undo
- [ ] Try Read Aloud

Local images load wherever Files allows access. For images in another folder, use **Open Image Folder** when prompted.

## Following updates

Changes saved by another app appear automatically. Pause Updates keeps the displayed version until you resume. Review Changes shows what changed without editing the file.
