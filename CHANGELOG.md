# Changelog

## Unreleased

- Add an iPhone/iPad MVP with Files, change review and Read Aloud.

## 1.7.0 — 2026-10-22

- Render GitHub alerts, math and Mermaid diagrams offline.
- Improve Mac compatibility and reproducible builds.

## 1.6.0 — 2026-10-22

- Print rendered documents with ⌘P and a compact PDF layout.
- Support safe GitHub-style HTML and authored image dimensions.

## 1.5.0 — 2026-10-14

- Add on-device Read Aloud, voice controls and saved positions.
- Polish playback, setup, settings and compact layouts.
- Add Spanish, Simplified/Traditional Chinese, Japanese, French and German.

## 1.3.0 — 2026-10-14

- Keep your place during updates; pause and resume saved files.
- Navigate headings, tasks and changes with keyboard shortcuts.
- Improve VoiceOver focus, announcements and change descriptions.
- Add document language detection and localization foundations.

## 1.2.2 — 2026-10-14

- Save checklists to Markdown with first-click permission, autosave and Undo/Redo.
- Review changes in a docked panel that keeps the document visible.
- Load local images without folder grants; remote images remain opt-in.
- Keep your scroll position when checking tasks.
- Improve Find focus, text-field Undo and accessibility.
- Fix duplicated table captions.

## 1.1.0 — 2026-10-07

- Stream live Markdown from Drafts and compatible editors while Marked stays closed.
- Pause/resume streaming and show the source app when available.
- Review changes individually or acknowledge all without editing the file.
- Separate reading controls from update status and word count.

## 1.0.0

- Read Markdown with tables, links, lists, code blocks and footnotes.
- Follow saved changes with automatic refresh and change review.
- Navigate outlines, find text, zoom and adjust reading width.
- Share System, Light or Dark appearance with Finder Quick Look.
- Preview Drafts through an optional action.
- Load local images with folder grants; allow HTTPS images per document.
- Install a signed, notarized DMG for Apple Silicon and Intel.

## 0.2.6 — Preview

- Automate signed, notarized DMG releases with checksums on GitHub.

## 0.2.5 — Preview

- Initial macOS viewer, Quick Look extension and Drafts action.
